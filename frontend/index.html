Fitur Unggulan SIGAB

🗺
Peta Interaktif Aset
Visualisasi persebaran aset tanah dan bangunan di seluruh wilayah Kabupaten Bojonegoro dengan basemap satelit dan batas kecamatan.
Buka Peta
🔍
Filter & Pencarian Aset
Cari dan filter aset berdasarkan kecamatan, desa, NIBAR, dan OPD pengelola. Klik marker untuk melihat detail informasi aset secara lengkap.
Coba Filter
📊
Statistik Real-Time
Data jumlah aset, total luas, dan sebaran per kecamatan diperbarui otomatis langsung dari basis data spasial PostgreSQL + PostGIS.
Pelajari Lebih
🔐
Panel Administrasi
Pengelolaan data aset secara langsung — tambah, edit, hapus, dan verifikasi data KIB A & C oleh staf BPKAD yang berwenang.
Login Admin
📥
Ekspor Laporan Excel
Unduh data KIB A (Tanah) dan KIB C (Bangunan) dalam format Excel terstruktur dengan filter kecamatan untuk kebutuhan pelaporan dan audit.
Unduh Data
📷
Dokumentasi Foto Aset
Setiap aset bangunan dilengkapi tautan foto dan denah yang dapat diakses langsung melalui popup peta tanpa perlu kunjungan lapangan.

Tentang Sistem

Pengelolaan Aset Daerah Berbasis Geospasial

SIGAB merupakan sistem informasi terintegrasi yang dirancang untuk mendukung pengelolaan aset milik Pemerintah Kabupaten Bojonegoro secara digital. Sistem ini memungkinkan pencatatan, pemutakhiran, dan pengawasan aset tanah serta bangunan dilakukan secara akurat, transparan, dan berkelanjutan sesuai prinsip Standar Akuntansi Pemerintahan (SAP).
